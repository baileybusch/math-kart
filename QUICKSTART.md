# 🎮 QUICK START - Play Math Kart NOW!

## For Parent: How to Run (30 seconds)

1. **Install & Run** (one command):
   ```bash
   npm install && npm run dev
   ```

2. **Open your browser** to the URL shown (usually `http://localhost:5173`)

3. **Start racing!** Use Arrow Keys or WASD to drive

That's it! The game loads instantly.

---

## What Your Child Will Do

1. **Click a track** (Forest to start, Desert unlocks later)
2. **Race!** Use arrow keys to drive the red kart
3. **Math problems appear** at yellow checkpoints ✓
4. **Click the right answer** to earn coins 💰
5. **Finish the race** to earn more coins (1st place = 50 coins!)
6. **Visit the shop** to buy upgrades and unlock the desert track

---

## Controls

- **Drive**: Arrow Keys ⬆️⬇️⬅️➡️ or WASD
- **Answer math**: Click the number buttons
- **Navigate menus**: Click with mouse

---

## Tips for Fun

- Try to get 1st place for maximum coins!
- Unlock the Desert track (costs 100 coins)
- Buy speed upgrades to go faster
- Change your kart color in the shop
- Wrong answers are OK - coins never go below 0!

---

## Math Topics

The game teaches:
- Addition & subtraction (2-digit numbers)
- Unit conversions:
  - Milliliters ↔ Liters (mL/L)
  - Grams ↔ Kilograms (g/kg)
  - Meters ↔ Centimeters (m/cm)

All appropriate for early 3rd grade!

---

## Troubleshooting

**Can't see the game?**
- Make sure the terminal shows "Local: http://localhost:5173"
- Try refreshing your browser
- Check that port 5173 isn't blocked

**Game too easy/hard?**
- Current difficulty is early 3rd grade
- More packs can be added later (see README.md)

**Reset progress?**
- Press F12 in browser
- Type: `localStorage.removeItem('mathKartSave')`
- Press Enter, then refresh page
