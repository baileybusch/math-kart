## For Parent: How to Run Locally (Alternative)

If you want to run it on your computer instead:

1. **Install & Run** (one command):
   ```bash
   npm install && npm run dev
   ```

2. **Open your browser** to the URL shown (usually `http://localhost:5173`)

3. **Start racing!** Use Arrow Keys or WASD to drive

## What Your Child Will Do

1. **Pick a track** (Forest to start, Desert unlocks later)
2. **Race!** Use on-screen buttons (iPad) or arrow keys (computer)
3. **Solve math** at yellow checkpoints ✓
4. **Earn coins** - correct answers give 5 coins! 💰
5. **Finish the race** to earn bonus coins (1st place = 50!)
6. **Visit the shop** to buy upgrades and unlock new stuff

## Controls

### iPad/Tablet
- **Tap left/right arrows** at bottom-left to steer
- **Tap up arrow** at bottom-right to go fast
- **Tap down arrow** at bottom-right to brake
- **Tap number buttons** for math answers

### Desktop Computer
- **Arrow Keys** ⬆️⬇️⬅️➡️ or WASD to drive
- **Click numbers** for math answers

## Math Topics (3 Packs Included!)

The game teaches:

**Addition & Subtraction:**
- 2-digit addition & subtraction
- Unit conversions (mL/L, g/kg, m/cm)

**Multiplication Facts:**
- Times tables (2, 5, 10)
- Basic multiplication (2-5 × 2-10)

**Division Facts:**
- Division with 2, 5, 10
- Basic division (no remainders)

All problems are early 3rd grade level!

## Troubleshooting

**On iPad - can't see controls?**
- Make sure you're in Safari (not Chrome)
- Rotate to landscape for best experience
- Tap fullscreen if prompted

**Can't see the game?**
- Try refreshing the page
- Check your internet connection
- Make sure JavaScript is enabled

**Reset progress?**
- Tap the menu (three lines) in Safari
- Choose "Developer Tools" → "Console"
- Type: `localStorage.removeItem('mathKartSave')`
- Press Enter, then refresh page
